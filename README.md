# PlotTwist

Сайт для выбора кино и планирования киновечера.

**[Открыть сайт](https://fara1009.github.io/plottwist/)**

## Возможности

- Квиз из четырёх вопросов с объяснением рекомендаций.
- Подбор для двоих: участники отвечают по очереди на одном устройстве.
- Вечерний набор: закуска, атмосфера, расписание и сохраняемый чек-лист.
- Личный список, статусы просмотра и оценки.
- Каталог из 24 фильмов, поиск, фильтры и подробности без спойлеров.

## Технологии

HTML, CSS, Bootstrap Grid 5.3.3, JavaScript и jQuery 3.7.1.
Библиотеки и постеры находятся в репозитории, интернет для работы не нужен.
Данные списка и последнего вечернего набора хранятся в localStorage
только на текущем устройстве и в текущем браузере.

## Запуск

Откройте папку через Live Server в VS Code или запустите статический сервер:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000. Можно открыть `index.html` напрямую,
но для надёжного сохранения между страницами рекомендуется сервер.

## Проверка

```sh
node checks.cjs
```

Проверяются 216 профилей квиза, 46 656 пар ответов, равноправие участников,
ограничения времени и нагрузки, переход через полночь и пути к файлам.

## Обновление подборки и кода

В подборке 24 фильма. Восемь прежних фильмов заменены, добавлены ещё шесть.
В подробностях фильма и вечернем наборе есть кнопка с проверенной прямой
ссылкой на страницу этого фильма на Rezka. Она открывается в новой вкладке.

JavaScript и CSS отформатированы. Основные части приложения подписаны
комментариями, правила подбора вынесены в понятные функции. Для изменения
каталога достаточно редактировать `assets/movies.js`, в том числе `watchUrl`.

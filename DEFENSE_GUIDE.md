# PlotTwist — подготовка к защите Final Project

## Демонстрация на 5–7 минут

1. Открой главную: покажи пять связанных страниц, поиск по названию, фильтр настроения и сортировку. Объясни, что каталог приходит из JSON, а карточки создаёт JavaScript.
2. Переключи EN → RU и открой другую страницу. Язык сохраняется в localStorage; переводятся названия, описания, подсказки и доступные названия элементов.
3. Пройди квиз. Выбери ограничение времени и покажи, что результаты его соблюдают. Прочитай причины подбора.
4. В режиме для двоих покажи проверку пустых имён, раздельные ответы, передачу устройства и общий результат. При смене языка текущий шаг и ответы сохраняются.
5. Добавь фильм в список, отметь просмотренным, поставь оценку и обнови страницу.
6. Собери вечерний набор на несколько человек с началом в 23:50: ингредиенты меняются, расписание помечает следующий день. Отметь пункт чек-листа и обнови страницу.
7. Покажи мобильный вид и диалог фильма. Открой диалог с клавиатуры, закрой Escape; обрати внимание на подписи форм, alt и видимый фокус.

## Файлы и связи

- Пять HTML-файлов задают страницу через `body[data-page]`, загружают стили и скрипты с `defer`. В HTML остаются семантические main/header/footer, сообщение загрузки и dialog.
- `assets/app.js` управляет интерфейсом. Сначала `Promise.all` ожидает каталог и словари. Затем создаются локализованные фильмы, читаются сохранения и `renderPage()` выбирает нужную страницу. Внутри файла разделы с комментариями: общие функции, навигация, каталог, квиз, вечерний набор, список, диалог и обработчики.
- `assets/data.js` загружает JSON через `fetch`, проверяет структуру и хранит Promise, чтобы не запрашивать каталог повторно в рамках страницы. `localize()` объединяет метаданные с переводом. `IntersectionObserver` подставляет `src` постеров рядом с видимой областью.
- `assets/data/movies.json` содержит 24 фильма. ID, продолжительность, жанры и настроение одинаковы для обоих языков. Удалённые из каталога постеры не входят в архив.
- `assets/i18n.js` загружает и кеширует словари. `t(key, values)` находит текст и подставляет значения вроде `{name}`. Английский служит значением по умолчанию. В localStorage записывается только код языка.
- `assets/locales/en.json` и `ru.json` содержат текст интерфейса и фильмов. Ключи и параметры в обоих словарях должны совпадать. Перевод выполняется при построении интерфейса, а не ручным поиском строк в готовой странице.
- `assets/engine.js` не работает с DOM: принимает фильмы и предпочтения, возвращает результаты и причины. Его можно проверить отдельно в Node.js.
- `assets/style.css` определяет внешний вид, адаптивность, фокус, состояния ошибок и режим уменьшенного движения.
- `assets/vendor/` содержит локальные Bootstrap Grid и jQuery. Bootstrap используется для сетки, jQuery — для эффектов; Bootstrap JS-плагины не нужны.
- `checks.cjs` проверяет подбор, JSON, словари, сохранение языка и пути ресурсов. `server.cjs` нужен только для локального запуска; GitHub Pages уже предоставляет HTTP.

## Как работает подбор

Ответы хранятся как коды: например, `mood: warm`, `genre: animation`, `duration: 100`, `intensity: 1`. Текст вопроса переводится, коды остаются одинаковыми.

Сначала отбираются фильмы, которые укладываются во время и допустимую эмоциональную интенсивность. Затем начисляются баллы: настроение +5, жанр +4, время +3, интенсивность +2. Точные совпадения настроения и жанра ставятся первыми. Если точного совпадения нет, показывается подходящая по обязательным ограничениям альтернатива с честным объяснением. Если нет допустимых фильмов, интерфейс предлагает изменить ответы.

Для двоих обязательные ограничения проверяются для каждого. Далее сравниваются: точность для обоих, меньший из двух индивидуальных баллов, сумма баллов и стабильный ID. Благодаря этому участники равноправны: перестановка их ответов не меняет подбор. Это алгоритм с правилами, не нейросеть и не случайная выдача.

`reasons()` возвращает данные вроде `{type: 'duration', value: '100'}`. Интерфейс превращает их в предложение на выбранном языке. При смене языка меняется объяснение, а не правила и результаты.

## Вопросы преподавателя

**Как мы использовали Bootstrap?** Для адаптивной сетки: `container`, `row` и `col-*`. Например, `col-lg-8` занимает восемь из двенадцати колонок на большом экране. Цвета, карточки и кнопки оформлены своим CSS.

**Зачем jQuery?** Для плавного открытия FAQ (`slideDown`/`slideUp`), появления вопросов и отсортированного каталога (`hide().fadeIn()`), а также анимации ошибки формы. `.stop(true, true)` убирает очередь эффектов при быстрых повторных действиях. При reduced motion интерфейс обходится без этих анимаций.

**Что делает `$(document).ready(...)`?** Запускает обработчик, когда DOM готов. В этом проекте скрипты загружаются с `defer`, поэтому DOM готов к их выполнению. Дополнительно приложение ожидает JSON через `await`; готовность DOM и готовность данных — разные вещи.

**Что такое `fetch`, Promise и await?** `fetch` возвращает Promise ответа. `await` ждёт его внутри async-функции. Нужно проверить `response.ok`, затем отдельно дождаться `response.json()`. Ошибка HTTP сама по себе не всегда отклоняет Promise, поэтому проверка статуса обязательна.

**Чем JSON отличается от JavaScript?** JSON — формат данных: двойные кавычки, без функций и комментариев. JavaScript исполняет алгоритмы. В проекте JSON хранит каталог и переводы, а JS их загружает и обрабатывает.

**Как найти ID через jQuery?** `$('#language-switch')` — ID начинается с `#`; `$('.movie-card')` ищет класс; `$('button')` ищет тег. Для чтения ID элемента можно использовать `$(this).attr('id')`.

**Разница `.text()` и `.html()`?** `.text()` вставляет обычный текст, `.html()` разбирает HTML-разметку. Имена пользователя нужно экранировать перед вставкой в шаблон. В проекте для этого есть `escapeHtml()`, а уведомления записываются через `textContent`.

**Что делают события click, input, change, keyup и mouseover?** Click реагирует на нажатие; input — на изменение вводимого текста; change — на выбор/подтверждение значения; keyup — на отпускание клавиши; mouseover — на попадание указателя на элемент, в том числе при переходе на его потомка. В проекте поиск использует input, выбор языка — change, кнопки — click. Не утверждай, что все перечисленные события обязательно применены в коде.

**Что делает `.css()`?** `$('.movie-card').css('opacity', 0.5)` задаёт стиль через jQuery. Обычно устойчивые состояния лучше оформлять CSS-классами. В PlotTwist основные стили находятся в style.css, а jQuery используется для эффектов.

**var, let, const?** Let/const имеют блочную область видимости. Const запрещает переназначать переменную, но не замораживает объект. Let подходит для изменяемого состояния. Var имеет область функции и особенности hoisting, поэтому в новом коде удобнее let/const.

**console.log и alert?** Console.log выводит данные разработчику в консоль. Alert показывает блокирующее окно пользователю. В проекте обычная обратная связь даётся неблокирующим toast с role=status; ошибки загрузки дополнительно пишутся через console.error.

**hide, fadeIn, fadeToggle?** Hide скрывает элемент; fadeIn показывает с изменением прозрачности; fadeToggle переключает видимость с плавным переходом. В проекте реально используется hide/fadeIn; FAQ использует slide-эффекты.

**Как работает валидация формы?** Имена обрезаются через trim, проверяются на пустое значение. При ошибке показывается сообщение, ставится aria-invalid, фокус переходит на проблемное поле. Атрибут aria-describedby связывает поле с объяснением. Поскольку нет серверной отправки, серверная валидация здесь не требуется; в настоящей контактной форме она нужна дополнительно к клиентской.

**Зачем localStorage?** Сохраняет строки между перезагрузками в пределах одного origin. Объект преобразуется через JSON.stringify, обратно — JSON.parse. Код обрабатывает ошибки и проверяет данные. Язык хранится отдельно от списка и набора. Это не база данных и не синхронизация между устройствами.

**Что означает доступность?** Страницей можно пользоваться с клавиатуры и вспомогательными технологиями: есть подписи, alt, skip link, фокус, aria-current и live-уведомления. У диалога связаны заголовок и описание; у прогресса — текущий шаг и границы.

## Дополнительные бонусы и новая палитра

Палитра теперь сливочная с винным акцентом. В тёмной теме используется глубокий тёплый фон со светлым розовым акцентом. Переключатель с солнцем/луной находится рядом с языком; `aria-pressed=true` означает включённую светлую тему.

Новый файл `assets/enhancements.js` отвечает за шесть возможностей:

1. **Тема (+3%)**: до загрузки CSS читает `plottwist:theme` и задаёт `html[data-theme]`. `toggleTheme()` сохраняет выбор, а CSS-переменные меняют весь интерфейс. При заблокированном localStorage тема работает на текущей странице.
2. **Появление при прокрутке (+3%)**: IntersectionObserver следит за блоками, `reveal()` запускает jQuery-анимацию прозрачности и CSS-переход положения. Попадание фокуса сразу раскрывает блок.
3. **Счётчики (+3%)**: данные каталога и личного списка попадают в `data-count`. При входе в видимую область requestAnimationFrame обновляет числа в течение 650 мс. Это динамические значения, а не заранее записанные кадры.
4. **Sticky / Scroll Spy (+2%)**: обработчик прокрутки сравнивает положение разделов с высотой шапки и меняет активную ссылку. `aria-current=location` указывает текущий раздел. requestAnimationFrame объединяет частые scroll-события в обновления по кадрам.
5. **«Наверх» (+2%)**: после 500 пикселей прокрутки появляется кнопка. Она плавно возвращает страницу к началу и переводит фокус на логотип.
6. **Копирование (+2%)**: кнопка в готовом наборе собирает текст из фильма, количества людей, ингредиентов, отмеченных пунктов, атмосферы и расписания. `navigator.clipboard.writeText()` возвращает Promise. При отказе появляется текстовое поле для ручного копирования.

При `prefers-reduced-motion` числа сразу показывают итог, блоки остаются видимыми, прокрутка выполняется без анимации. Все новые подписи переведены на EN/RU. Проверки новых функций находятся в `enhancements-checks.cjs` и запускаются вместе с основными проверками. Общий бонус ограничен +10%.

На демонстрации переключи тему и перейди на другую страницу, чтобы показать сохранение. На главной нажми «Каталог фильмов» и «Вопросы», покажи подсветку текущего раздела. Прокрути к счётчикам и нажми «Наверх». Создай вечерний набор, отметь пункт, скопируй план и вставь его в редактор.
